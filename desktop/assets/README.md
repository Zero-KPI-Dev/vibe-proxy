# Desktop visual assets

`appicon.svg`, `tray.svg`, and `tray-template.svg` are the editable source
artwork for the Vibe Proxy Flow Gate mark.

Checked-in build inputs are generated from those sources:

- `../build/appicon.png` (1024 x 1024 RGBA);
- `../wailsapp/assets/tray.png` (64 x 64 color tray icon);
- `../wailsapp/assets/tray-template.png` (64 x 64 monochrome macOS template).

The platform application icons are then generated by
`desktop/build/Taskfile.yml` into `icons.icns` and `icon.ico`. Generated assets
remain checked in so release builds do not need an SVG renderer.
